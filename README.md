# Slime Dungeon

## Story

世界には魔王はおらず、スライムが徘徊するダンジョンがあった。
冒険者はダンジョンに潜って今日もクエストをこなし日々の糧を得ていた。

このゲームは、ただスライムだけが現れるダンジョンに潜って、ギルドで受注したクエストを粛々とこなすだけのゲームです。

倒すべき魔王も、救うべき姫も、集めるべきクリスタルもありません。

## System Requirement

.NET 10.0 + SDL3 が必要ですが、SDL3はSDL3-CS.Nativeパッケージにより自動的に取得されます。

## Game

### 冒険者登録

ゲームを起動すると、冒険者登録を求められます。
名前と性別を尋ねられますが、冒険者の能力に性別による差はありません。

各パラメータはある程度のゆれをもって初期値が決定されます。

### 冒険者ギルド

冒険者登録が済むとギルドに移動します。
右側にはあなたの冒険者カードとそのほかのステータスが表示されています。

ギルドではクエストの受注、報告、ダンジョンへの移動、ショップ、回復などを行うことができます。

クエストをこなすことで冒険者ランクが上がります。
また、何らかの条件を満たすことで、称号を得ることができ、獲得済みの称号をギルドカードに表示することができます。

クエストを期日までに完了できない場合はクエスト失敗となります。

### ダンジョン

ダンジョンは、入るたびに変化します。ギルドにつながる階段が一カ所あり、階段でスペースキーを押すとギルドに戻れます。
ダンジョンに入って出ると一日が経過します。

ダンジョン内にはスライムがいて宝箱があります。
宝箱からは様々なアイテムが出ますが、初期状態で持っている袋は3つしかものを持てませんので、アイテムを捨てたり装備したりしてやりくりしてください。
もしかすると、大きなサイズの鞄が出てくるかもしれませんので、それまでは出たり入ったりしながらクエストをこなしてください。

### 戦闘

戦闘はターン制コマンドバトルです。

### ゲームオーバ

死んでしまったらゲームオーバです。
生き返らせてくれる教会のような不思議な施設はありません。

死んでしまったら、冒険者登録からやり直してください。

初期状態の冒険者は意外とあっさり死んでしまいます。
ある程度の強さになるまでは慎重に冒険をしてください。
ある程度になっていても相手が悪いと死んでしまうかもしれません。
ベテランも油断めさることなく。

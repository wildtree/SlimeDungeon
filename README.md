# Slime Dungeon

## Story

世界には魔王はおらず、スライムが徘徊するダンジョンがあった。
冒険者はダンジョンに潜って今日もクエストをこなし日々の糧を得ていた。

このゲームは、ただスライムだけが現れるダンジョンに潜って、ギルドで受注したクエストを粛々とこなすだけのゲームです。

倒すべき魔王も、救うべき姫も、集めるべきクリスタルもありません。

## System Requirement

.NET 10.0 + SDL3 が必要ですが、SDL3はSDL3-CS.Nativeパッケージにより自動的に取得されます。

## Game

### 冒険者登録

ゲームを起動すると、冒険者登録を求められます。
名前と性別を尋ねられますが、冒険者の能力に性別による差はありません。

各パラメータはある程度のゆれをもって初期値が決定されます。

### 冒険者ギルド

冒険者登録が済むとギルドに移動します。
右側にはあなたの冒険者カードとそのほかのステータスが表示されています。

この世界であなたがいけるのは、ギルド、商店、鍛冶屋、薬局、そしてダンジョンだけです。

ギルドではクエストの受注、報告、回復などを行うことができます。

クエストをこなすことで冒険者ランクが上がります。
また、何らかの条件を満たすことで、称号を得ることができ、獲得済みの称号をギルドカードに表示することができます。

クエストを期日までに完了できない場合はクエスト失敗となります。

#### 商店

商店ではアイテムの売買を行うことができます。
武器や防具も売られていますが、あまり期待してはいけません。
この世界では金属はある種のスライムからのみ得られ、その素材はそこそこ貴重なので、金属素材の武器や防具は販売されていないのです。

#### 薬局

薬局ではポーションを調合することができます。
素材は薬草の類です。
ポーションはHPやMPを回復することができます。
そして回復効果は薬草そのものより高いです。

#### 鍛冶屋

鍛冶屋ではスライムから得た素材を使って、武器や防具を作成できます。
ダンジョンに潜り素材を得て武器や防具を更新することができれば、生き残っていけるかもしれません。

### ダンジョン

ダンジョンは、入るたびに変化します。ギルドにつながる階段が一カ所あり、階段でスペースキーを押すとギルドに戻れます。
ダンジョンに入って出ると一日が経過します。

なので、頻繁にダンジョンからの出入りを繰り返すと、あっという間に日数が経過して、クエストを失敗するなどしてしまいます。

ダンジョン内にはスライムがいて宝箱があります。
宝箱からは様々なアイテムが出ますが、初期状態で持っている袋は3つしかものを持てませんので、アイテムを捨てたり装備したりしてやりくりしてください。
もしかすると、大きなサイズの鞄が出てくるかもしれませんので、それまでは出たり入ったりしながらクエストをこなしてください。

### 戦闘

戦闘はターン制コマンドバトルです。

「たたかう」「まほう」「アイテム」「にげる」の各コマンドがあります。
「たたかう」は武器による物理攻撃でSTRに応じたダメージを相手に与えます。攻撃対象はスライム単体になります。
「まほう」は、ダンジョンの宝箱から得られる「スクロール」によって覚えていれば使うことができます。攻撃魔法は常に敵全体に作用します。INTに応じたダメージを相手に与えます。
「アイテム」は二つあるアイテムスロットに装備しているアイテムを使用するためのコマンドです。攻撃用のアイテムであれば攻撃が、回復系のアイテムであれば回復が行われます。
「にげる」は戦闘からの離脱です。AGLに応じて成功率が変化します。

攻撃の順序はAGLに応じて決まります。
最初のうちはスライムの方が素早いかもしれません。
その場合はエンカウントから自分のターンまでに攻撃を受けて死んでしまうかもしれません。

たかがスライムと侮ってはいけません。
この世界で最弱の存在は、初級の冒険者なのかもしれないのです。

### ゲームオーバ

死んでしまったらゲームオーバです。
生き返らせてくれる教会のような不思議な施設はありません。

死んでしまったら、冒険者登録からやり直してください。

初期状態の冒険者は意外とあっさり死んでしまいます。
ある程度の強さになるまでは慎重に冒険をしてください。
ある程度になっていても相手が悪いと死んでしまうかもしれません。
ベテランも油断めさることなく。
